管理会社変更の総会の流れ｜理事会が準備する資料と進め方

最終更新: 2026年6月21日

管理会社を変更するには、理事会だけで完結しないことがあります。総会での承認が必要になる場合が多く、住民に分かりやすく説明する準備が欠かせません。

結論

管理会社変更の総会では、変更理由、比較結果、新契約の内容、移行スケジュールを説明し、承認を得る流れになります。事前資料を整理し、質問に答えられる状態を作ることが大切です。

本文

1. 理事会で変更理由を整理する

総会に出す前に、理事会で管理会社変更を検討する理由を整理します。対応の遅さ、報告内容、委託費、業務範囲、担当者体制など、住民に説明できる形にまとめます。

感情的な表現ではなく、事実ベースで整理することが重要です。過去の理事会議事録、見積書、比較表、改善要望の履歴などがあると、説明しやすくなります。たとえば、報告書の提出遅れ、会計説明の不足、清掃品質の指摘、緊急対応の連絡経路などを、発生日と対応結果を含めて一覧化すると、住民に対して「なぜ変更を検討したのか」を説明しやすくなります。

2. 複数社比較の資料を作る

管理会社を変更する場合は、候補会社の比較資料を用意します。比較項目は、委託費、業務範囲、理事会支援、緊急対応、担当者体制、引継ぎ方法などです。

住民は専門的な違いまで把握していないことが多いため、見やすい比較表があると理解しやすくなります。総額だけでなく、何が含まれるかを並べて示します。比較表では、現管理会社、新候補、現状維持案を横に並べ、委託費、管理員・清掃、会計報告、理事会支援、緊急受付、引き継ぎ支援、初年度の重点対応を同じ項目で見せると、判断材料がそろいます。

3. 総会資料には契約内容と移行時期を入れる

総会議案には、新しい管理会社の契約開始日、委託費、主な業務内容、現在の管理会社との契約終了予定日、引継ぎの流れを記載します。

管理会社変更では、通帳、会計資料、修繕履歴、設備資料、鍵、契約書類などの引継ぎが発生します。移行時期が曖昧だと、住民に不安を与えることがあります。総会資料には、承認日、旧契約終了予定日、新契約開始予定日、引き継ぎ期間、住民への案内時期、初回理事会での確認予定を時系列で入れると、変更後の流れを共有しやすくなります。

契約内容の説明では、委託費の総額だけでなく、管理員業務、清掃、会計、理事会支援、総会支援、緊急対応、長期修繕計画支援の扱いを分けて示します。住民にとっては「安くなるか」だけでなく、「今までと何が変わるか」が判断材料になります。旧契約と新契約の違いを表にしておくと、総会当日の質問に答えやすくなります。

総会議案では、承認を求める内容も明確にします。新管理会社との契約締結を承認するのか、契約条件の最終調整を理事会に委任するのか、旧管理会社への解約通知を進めるのかを分けて書きます。承認範囲が曖昧だと、総会後の契約手続きで住民から追加説明を求められることがあります。

4. 総会当日は質問への対応を想定する

総会では、費用は下がるのか、サービスは悪くならないのか、引継ぎは大丈夫か、今の管理会社との関係はどうなるのか、といった質問が出やすくなります。

理事会は、比較した理由と判断材料を落ち着いて説明します。想定問答を作る場合は、費用、業務品質、引き継ぎ、現管理会社との関係、契約解除の手続き、住民窓口の変更を分けて用意します。分からないことを無理に断定せず、確認が必要な事項は後日回答する形にすると、議事進行が安定します。

5. 承認後のスケジュールを示す

総会で承認を得た後は、契約手続き、旧管理会社への連絡、資料引継ぎ、住民への案内、新管理会社の初回対応などが続きます。総会資料の段階で、おおまかなスケジュールを示しておくと、住民の不安を減らせます。

例えば、承認後1か月以内に契約手続き、翌月から引継ぎ、契約開始月に住民向け案内、初回理事会で運営状況を確認する、といった流れです。実際の日付は管理組合ごとに異なりますが、流れを示すだけでも理解しやすくなります。

承認後の作業は、理事会側、旧管理会社側、新管理会社側に分けて管理します。理事会側は契約書確認、住民案内、初回理事会の議題設定を行い、旧管理会社側は会計資料、通帳関係、図面、鍵、契約台帳の引き渡しを行います。新管理会社側には、初回点検、住民窓口の周知、会計移行、未処理案件の確認を依頼すると、移行漏れを減らしやすくなります。

6. 変更後の確認事項を理事会で決める

管理会社変更は、総会で承認されたら終わりではありません。変更後の数か月は、会計処理、管理員業務、清掃状況、問い合わせ対応、理事会資料の質を確認します。

理事会では、初回、3か月後、半年後などのタイミングで確認する項目を決めておくと、変更後の不具合に気づきやすくなります。住民からの問い合わせも記録し、新管理会社と共有すると改善につなげやすくなります。

確認項目は、契約前に期待した改善点と対応させます。たとえば、報告が遅いことが変更理由だった場合は、理事会資料の提出日、月次報告の内容、問い合わせ回答までの日数を確認します。清掃品質が理由だった場合は、清掃仕様、巡回結果、住民からの指摘件数を追うことで、変更後の評価が感覚だけになりにくくなります。

総会後に住民へ出す案内も準備しておきます。承認結果、新管理会社の名称、契約開始日、問い合わせ先、管理員や清掃体制の変更点、初回対応の予定を簡潔に知らせます。総会に出席していない住民にも同じ情報が届くようにしておくと、変更直後の問い合わせを整理しやすくなります。

初回理事会では、総会で出た質問と変更後の実務状況を照合します。総会で不安が出た項目を優先して確認すると、住民説明と実際の運営がつながりやすくなります。

まとめ

管理会社変更の総会では、変更理由、比較結果、契約内容、移行スケジュールを整理して説明します。住民が判断しやすい資料を用意することが、承認に向けた実務上のポイントです。
